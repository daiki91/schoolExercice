# 🧠 QCM AI Service - Correction intelligente des QCM

Ce microservice utilise *FastAPI* et *un moteur IA (DeepSeek via Ollama)* pour corriger automatiquement des *questions à choix multiples (QCM)* soumises par des étudiants, attribuer une note, et fournir un feedback détaillé pour chaque réponse.

---

## 🚀 Fonctionnalités principales

- 🔍 Analyse et correction automatique des QCM
- 🧠 Feedback pédagogique pour chaque question
- 📊 Calcul de la note finale sur 20
- 🗂️ API RESTful avec FastAPI
- ⚙️ Déploiement facile avec Docker
